# Harkat Physiotherapy (concept)

A concept website for a physiotherapy clinic in Johar Town, Lahore.
Designed and built by NexaFlow with Next.js.

- Range-of-motion dial that animates on load
- Conditions explained in plain words, with typical session counts
- Home visits, female physiotherapist option and clear fees
- Booking requests sent to WhatsApp

```bash
npm install
npm run dev
```

All text, fees and photos are in `components/data.ts`.
